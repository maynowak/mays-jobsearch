# FAQ

**Brauche ich ein Konto?**
Für die Jobsuche nicht. Für RIS-gespeicherte Bewerbungen, CVs und
Suchprofile ist Login plus Freigabe/Einwilligung nötig.

**Wird mein CV-PDF hochgeladen?**
Nein. Die Textextraktion läuft im Browser; nur der extrahierte Text wird für
die jeweilige Analyse verwendet.

**Was ist der Unterschied zwischen Session und RIS?**
Session bleibt im Tab und endet mit dem Reload. RIS speichert dauerhaft im
Konto, sofern die Capability- und Consent-Gates erfüllt sind.

**Erstellt ein eigenes Anschreiben eine neue Version?**
Nein. Es ändert nur den Entwurf; bestehende Versionen bleiben unverändert.

**Ist die KI-Ausgabe garantiert?**
Nein. Sie ist ein Vorschlag; prüfe Originalanzeige und Text.

**Was macht der Screenshot-Modus?**
Er blendet Radar und schwebende Bedienelemente für eine saubere Darstellung
aus. Es wird kein Screenshot erstellt oder übertragen.

**Warum ist der CV-Editor-Radar manchmal nicht sichtbar?**
Im Screenshot-Modus wird er bewusst ausgeblendet. Beim Verlassen erscheint er
wieder.

**Warum schlägt `cv-builder-workflow-02a` fehl?**
Der Test erwartet einen veralteten Buttontext. Das ist eine Test-Altlast, keine
Produktregression.
