# Applications

Die Bewerbungsverwaltung liegt unter **Profil → Bewerbungen**.

## Anlegen

**Neue Bewerbung** → Stellenbeschreibung einfügen → optional Titel,
Unternehmen, Standort, URL → **Als Entwurf anlegen**.

## Bearbeiten

**Bewerbungsdaten bearbeiten** öffnet das Formular. Der Dirty-State vergleicht
echte Werte:

- unverändert → Tab-/Bewerbungswechsel sofort;
- geändert → Dialog **Ungespeicherte Änderungen** mit **Speichern und
  wechseln**, **Änderungen verwerfen**, **Weiter bearbeiten**;
- Speicherfehler → Dialog und alle Eingaben bleiben erhalten.

## Eigenes Anschreiben

Im Tab **Dokumente**: **Eigenes Anschreiben hinterlegen/bearbeiten** →
Text schreiben → **Eigenes Anschreiben speichern**. Keine KI, keine neue
Version, bestehende Versionen bleiben unverändert.

## Speicherung

Session-Entwürfe bleiben im Tab. RIS-Entwürfe werden nur nach Login,
serverseitiger Freigabe und Einwilligung dauerhaft gespeichert. Die App zeigt
den Modus an und überträgt Session-Daten nicht automatisch.
