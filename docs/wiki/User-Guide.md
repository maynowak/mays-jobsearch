# User Guide

Die vollständige Anleitung steht im Repository:
[Benutzerhandbuch](https://github.com/maynowak/mays-jobsearch/blob/main/docs/USER_GUIDE.md).

## Kurzüberblick

- **Profil:** sechs Bereiche mit stabiler Header-/Sidebar-Struktur.
- **Bewerbungen:** anlegen, bearbeiten, filtern, Status und Wiedervorlagen.
- **Eigenes Anschreiben:** ohne KI schreiben, speichern, Versionen unverändert.
- **KI-Anschreiben:** Assistent, Vergleich und explizite Versionierung.
- **CV-Import:** PDF lokal im Browser analysieren, Vorschläge prüfen.
- **CV-Editor:** acht Abschnitte, Live-Vorschau, Templates, PDF-Export.
- **Radar und Turbo-Hände:** Navigation und Scrollen in den Fullpage-Workspaces.
- **Expand/Collapse und Screenshot-Modus:** Ansichtsfunktionen ohne Datenänderung.

## Wichtige UI-Bezeichnungen

| Aktion | Deutsche Oberfläche |
| --- | --- |
| Bewerbung bearbeiten | Bewerbungsdaten bearbeiten |
| Ungespeicherte Änderungen | Speichern und wechseln / Änderungen verwerfen / Weiter bearbeiten |
| Eigenes Anschreiben | Eigenes Anschreiben hinterlegen / bearbeiten / speichern |
| CV-Import | PDF importieren |
| Alle Abschnitte | Alle Abschnitte aufklappen / einklappen |
| Screenshot | 📸 Screenshot-Ansicht / Screenshot-Ansicht beenden |
| CV-Editor-Ansicht | Ansicht wechseln |
| Erster Fehler | Zum ersten Fehler |
