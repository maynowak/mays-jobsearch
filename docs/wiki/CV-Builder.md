# CV Builder

Der CV-Workspace kombiniert Importvorschau und strukturierten Editor.

## Import

1. **PDF importieren** wählen.
2. PDF lokal im Browser analysieren lassen (die Datei wird nicht hochgeladen).
3. **Lebenslauf analysiert** abwarten.
4. Erkannte Abschnitte und Prüfliste kontrollieren.
5. **Angaben übernehmen** → **Auswahl übernehmen**.

Die Vorschau bietet Abschnittsauswahl, Status, Details, Filter, Pagination und
manuelle Zuordnung. Nichts wird automatisch übernommen.

## Editor

Acht Abschnitte, Live-Vorschau und die Templates **Klassisch**, **Modern**,
**Kompakt**. Aktionen: **Entwurf übernehmen**, **PDF herunterladen**,
**PDF dauerhaft speichern** (nur mit RIS-Freigabe).

## Radar, Expand/Collapse, Screenshot

- **Importübersicht** / **Abschnittsübersicht** öffnet die Radarziele.
- **Alle Abschnitte aufklappen/einklappen** ändert nur die Ansicht; Radar
  bleibt sichtbar.
- **📸 Screenshot-Ansicht** (Import) bzw. **Ansicht wechseln** (Editor)
  blendet Radar und schwebende Bedienelemente aus.
- Beim Verlassen wird der vorherige Aufklappzustand wiederhergestellt.
- Keine Ansichtsaktion speichert Daten oder startet KI/ATS/RIS.
